## Eteisnet

**Eteisnet, S.A.S.** is a software company based in Hermosillo, Sonora, Mexico. We build **SM7**.

### SM7
An end-to-end encrypted messenger for Android and iOS, with no cloud backups and no trust in the server: only the people in a conversation can read it.

[Google Play](https://play.google.com/store/apps/details?id=net.eteis.mensajero) · [App Store](https://apps.apple.com/app/id6805260173) · [eteis.net](https://www.eteis.net)
